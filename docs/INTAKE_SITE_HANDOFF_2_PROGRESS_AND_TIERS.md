# Site handoff 2: the progress bars and the tier table

Ready to send to whoever maintains <https://vietnamhearts.org/>, after [handoff 1](INTAKE_SITE_HANDOFF_1_LINKS.md).

This is the only place in the intake design where something other than a link has to be pasted, and the whole point of the shape below is that it is pasted **once**.
After that, the numbers and even whole new projects change in the team's spreadsheet and the website follows by itself.

## Placeholders to fill in before sending

| Placeholder | Where to get it |
|---|---|
| `<CHART_IFRAME>` | In the spreadsheet: File -> Share -> Publish to web -> pick the `Progress chart` tab or its chart -> Embed -> copy the whole `<iframe ...></iframe>` |
| `<TIERS_IFRAME>` | The same, for the `Donation tiers` tab. Only needed when the team is ready to show the tier table |
| `<SPREADSHEET_ID>` | Only for the styled version at the bottom. The long id in the spreadsheet URL between `/d/` and `/edit` |

## Do these two things in the spreadsheet first

1. **Publish only the `Progress chart` tab** (and later `Donation tiers`).
   File -> Share -> Publish to web, pick the tab or the chart by name, never "Entire document".
   Publishing the response tab would put every submitter's name, email address and phone number on a public URL.
   Publishing the team's own `Progress` tab rather than the `Progress chart` formula tab would expose the private rows and the notes column, which is exactly why there is a `QUERY` between them.
2. **Check that `Show on site` says `NO` on anything not ready to be public.**
   The published chart reads only the rows marked `YES`.

Apps Script has no API for publishing to the web, so neither of those can be automated.
They appear as the two **Publish to web** steps in the manual steps list of the email `buildIntake()` sends.

## Why this is not fed from the GoFundMe automatically

Worth being able to answer, because it is the first thing anyone asks.

- **There is no public GoFundMe API** for reading a campaign's raised amount. What exists is GoFundMe Pro, for campaigns hosted on that product, not for a consumer `gofundme.com/f/...` fundraiser.
- **The legacy embed widget is gone.** The old `/widget/medium` and `/widget/large` URLs now return the full campaign page, several hundred kilobytes of single-page app, not a widget.
- **An iframe of the campaign is on a countdown.** Both the campaign page and the widget path return a `content-security-policy-report-only` header with a `frame-ancestors` partner allowlist that does not include `vietnamhearts.org`. Report-only means it is not enforced yet, so an iframe would render today - and would go blank, with no notice and no error anybody at Vietnam Hearts would see, the day that header is promoted to enforcing. That is the entire purpose of shipping a report-only policy.
- **Scraping the page works and should still be rejected.** The figures are in the page's internal Next.js payload, which carries no compatibility contract, and a scraper needs something to run it on a schedule, which means new infrastructure for a design whose premise is adding none.

So one volunteer types one number once a month, in the same sitting as the rest of the sheet work.

## The styled version, for later

Not sent with the message above.
It depends on one unverified step: the browser has to allow a cross-origin read of the published CSV.
Test it once from any static page before using it, and if the read is blocked, stay on the iframe.

It renders one bar per published row, so a Tết gift drive and the rice fund can both have a goal, and it shows nothing at all rather than a wrong number.

```html
<!-- Vietnam Hearts donation progress bars, one per project. Reads the
     published "Progress chart" tab. Shows nothing rather than a wrong number. -->
<div id="vh-progress" style="font-family:inherit;max-width:560px;margin:0 auto"></div>
<script>
(function () {
  var SHEET_ID = '<SPREADSHEET_ID>';
  var SRC = 'https://docs.google.com/spreadsheets/d/' + SHEET_ID +
            '/gviz/tq?tqx=out:csv&sheet=Progress%20chart';

  var root = document.getElementById('vh-progress');
  if (!root) { return; }

  function num(v) {
    var n = parseFloat(String(v || '').replace(/[^0-9.\-]/g, ''));
    return isFinite(n) ? n : NaN;
  }

  // Minimal CSV reader: handles quoted cells and commas inside them, which
  // project names will eventually contain.
  function parseCsv(text) {
    var rows = [], row = [], cell = '', q = false, i;
    for (i = 0; i < text.length; i++) {
      var c = text[i];
      if (q) {
        if (c === '"' && text[i + 1] === '"') { cell += '"'; i++; }
        else if (c === '"') { q = false; }
        else { cell += c; }
      } else if (c === '"') { q = true; }
      else if (c === ',') { row.push(cell); cell = ''; }
      else if (c === '\n') { row.push(cell); rows.push(row); row = []; cell = ''; }
      else if (c !== '\r') { cell += c; }
    }
    if (cell !== '' || row.length) { row.push(cell); rows.push(row); }
    return rows;
  }

  function bar(name, raised, remaining) {
    var goal = raised + remaining;
    var pct = goal > 0 ? Math.max(0, Math.min(100, (raised / goal) * 100)) : 0;
    var wrap = document.createElement('div');
    wrap.style.margin = '0 0 18px';
    var head = document.createElement('div');
    head.style.cssText = 'display:flex;justify-content:space-between;' +
      'align-items:baseline;gap:12px;margin-bottom:6px';
    var left = document.createElement('strong');
    left.textContent = name;
    var right = document.createElement('span');
    right.style.cssText = 'opacity:.7;font-size:.9rem;white-space:nowrap';
    right.textContent = Math.round(pct) + '% of ' + goal.toLocaleString('en-US');
    head.appendChild(left); head.appendChild(right);
    var track = document.createElement('div');
    track.style.cssText = 'background:#e9e4da;border-radius:999px;height:14px;' +
      'overflow:hidden';
    var fill = document.createElement('div');
    fill.style.cssText = 'height:100%;width:' + pct.toFixed(1) + '%;' +
      'background:#7a8c6b;border-radius:999px';
    track.appendChild(fill);
    wrap.appendChild(head); wrap.appendChild(track);
    return wrap;
  }

  fetch(SRC).then(function (r) { return r.text(); }).then(function (csv) {
    var rows = parseCsv(csv.trim());
    var frag = document.createDocumentFragment();
    var shown = 0;
    rows.forEach(function (cells, idx) {
      if (idx === 0) { return; }                 // header row
      var name = String(cells[0] || '').trim();
      var raised = num(cells[1]);
      var remaining = num(cells[2]);
      // Blank beats wrong: skip any row that is not fully numeric.
      if (!name || !isFinite(raised) || !isFinite(remaining)) { return; }
      frag.appendChild(bar(name, raised, remaining));
      shown++;
    });
    if (shown) { root.appendChild(frag); }
  }).catch(function () { /* leave the area empty */ });
})();
</script>
```
